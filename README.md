# Hexapod Robot - Autonomous Walking Platform

**Full-cycle robotics project: from 3D design to functional prototype**

## 📋 Project Overview

This project demonstrates the complete development cycle of an autonomous hexapod robot. The robot features a custom 3D-printed mechanical design, ESP32-based control system, and proprietary gait algorithms for stable locomotion.

## 🎯 Technical Specifications

| Category | Details |
|----------|---------|
| **Microcontroller** | ESP32-DevKitC (Dual-core, 240MHz) |
| **Actuators** | 18x TD-8320MG Servos |
| **Wireless** | nRF24L01+ 2.4GHz Transceiver |
| **Power System** | 12.6V 3000mAh Li-Po with voltage regulation |
| **Mechanical Design** | KOMPAS-3D (parametric modeling) |
| **Fabrication** | Creality Ender |
| **Control Interface** | Custom RF remote with joystick input |
